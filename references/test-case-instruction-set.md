# 

## 测试计测试用例模版指令集划编写规范

## 一、测试用例编写规范

## 一点一、测试用例模版

1. 测试需求测试点方法：场景法、错误推测法、边界值、等价类、精确到字段级
2. 测试用例模版：测试编号、测试标题、测试模块、测试方法、前置条件、测试步骤、预期结果、优先级

## 一点二、UI自动化方法

1. UI执行方法：固定使用 Python + Playwright for Python + Pytest 执行 UI 自动化测试
2. 页面组织方式：固定使用 POM（Page Object Model），页面定位器与页面动作必须封装在页面对象层
3. 用例组织方式：测试用例必须按测试用例模版字段生成结构化数据，并由自动化测试脚本读取后执行
4. 配置与数据方式：运行配置、页面定位器、测试数据可使用 YAML 管理，不得直接把大量配置硬编码到测试脚本中
5. 报告与证据方式：执行后必须输出测试结果，并保留截图等失败证据；如项目已接入 Allure，则应输出 Allure 报告结果
6. 架构一致性要求：不得擅自切换为与当前工程架构不一致的执行方式，例如 JavaScript / TypeScript + Playwright Test

## 一点三、AI页面结构识别规则

1. 当 AI 接收到用户输入的URL时，必须先识别页面结构，采用真实额定位，再生成测试用例
2. AI 不得在未识别页面结构前，直接编写测试用例
3. AI 识别页面时，必须至少识别以下内容：
   - 页面名称
   - 页面主功能
   - 页面中的核心交互区域
   - 页面中的可操作元素类型
   - 页面中的主要业务流程入口
4. AI 在识别页面元素时，必须按以下类型归类：
   - 文本输入框
   - 选择项控件
   - 时间控件
   - 数字输入控件
   - 附件上传控件
   - 按钮
   - 列表
   - 查询条件区域
   - 弹窗
   - 权限相关入口或操作
5. 如果一个元素同时具备多种特征，应按其主要业务作用归类
6. AI 必须按以下顺序识别页面：
   - 先识别页面整体用途
   - 再识别页面中的核心流程
   - 再识别表单字段
   - 再识别按钮与操作入口
   - 再识别列表、查询区、弹窗等补充区域
7. AI 不得跳过页面整体识别，直接进入字段级测试点生成
8. AI 在完成页面识别后，必须形成结构化识别结果，至少包括：
   - 页面名称
   - 页面主流程
   - 元素名称
   - 元素类型
   - 元素用途
   - 是否属于主流程关键元素
9. 如果无法识别某个元素的真实业务含义，应标记为“待确认”，不得伪造业务含义
10. 如果用户未提供产品文档、前后端代码或足够的页面信息，AI 仍可先基于真实页面可见结构完成识别
11. 在输入不足时，AI 允许先识别：
   - 元素类型
   - 页面基础流程
   - 通用交互关系
12. 在输入不足时，AI 不得伪造：
   - 复杂业务规则
   - 后端校验逻辑
   - 数据库存储逻辑
   - 权限细节
13. AI 在页面识别阶段，禁止：
   - 未识别页面结构就直接写测试用例
   - 把页面上不存在的元素强行补出来
   - 把通用控件误写成已确认业务规则
   - 在没有证据时伪造字段约束

## 一点四、AI基于页面结构生成测试用例规则

1. AI 只有在完成页面结构识别后，才允许生成测试用例
2. 如果页面结构识别未完成，则测试用例生成不能视为合格
3. AI 在生成测试用例时，必须将“页面元素类型”映射到本指令集中的对应测试点章节，不得自由发挥
4. 映射规则如下：
   - 文本输入框 -> 文本类型字段测试点
   - 选择项控件 -> 选择项类型字段测试点
   - 时间控件 -> 时间类型字段测试点
   - 数字输入控件 -> 数字类型字段测试点
   - 附件上传控件 -> 附件上传字段测试点
   - 按钮 -> 按钮类功能测试点
   - 列表 -> 列表页测试点
   - 查询条件区域 -> 查询条件测试点
   - 弹窗 -> 弹窗类功能测试点
   - 权限入口或受限操作 -> 权限类测试点
5. AI 在生成页面测试用例时，必须同时考虑：
   - 页面整体场景
   - 字段级测试点
   - 操作级测试点
6. AI 不得只生成字段测试，而不生成页面主流程测试
7. AI 必须按以下顺序生成测试用例：
   - 先生成页面主流程用例
   - 再生成主流程关键字段用例
   - 再生成主按钮或主操作用例
   - 最后生成补充型用例
8. 如果页面为表单类页面，且输入信息不足，AI 至少应优先生成以下类型的测试用例：
   - 页面可正常打开
   - 必填项校验
   - 主按钮点击后的基础校验
   - 一个成功场景或一个失败场景
9. AI 生成的每条测试用例，必须包含：
   - 测试编号
   - 测试标题
   - 测试模块
   - 测试方法
   - 前置条件
   - 测试步骤
   - 预期结果
   - 优先级
10. AI 不得省略为不完整用例描述
11. AI 在生成测试用例时，必须从以下方法中选择适用方法：
   - 场景法
   - 错误推测法
   - 边界值
   - 等价类
   - 精确到字段级
12. 如果只是页面主流程验证，应优先使用场景法
13. 如果是必填、非法输入、空值、异常提交，应优先考虑错误推测法、边界值或等价类
14. AI 在生成测试用例时，必须能够说明每条测试用例来源于本指令集中的哪一类测试点
15. 用例来源说明示例如下：
   - 来源：文本类型字段测试点 > 必填校验
   - 来源：按钮类功能测试点 > 点击交互校验
   - 来源：列表页测试点 > 页面展示校验
16. 如果无法说明来源，则该测试用例不能视为严格按模板生成
17. 如果缺少真实业务规则，AI 可以先生成通用测试用例，但必须满足：
   - 用例基于真实页面结构
   - 用例来源可映射到本指令集
   - 不伪造具体业务文案和隐藏规则
18. AI 在生成测试用例时，禁止：
   - 不经过页面结构识别直接生成用例
   - 不引用本指令集对应测试点直接自由发挥
   - 伪造页面不存在的字段、按钮、列表或弹窗
   - 在无证据情况下伪造业务成功条件或失败文案
   - 只生成演示性样例，不生成可落地测试用例

## 二、字符类型

## 二点一、文本类型字段测试点

### 1. 长度校验

1. 验证最小长度是否符合要求
2. 验证最大长度是否符合要求
3. 验证超过最大长度时是否拦截或提示
4. 验证为空时是否允许提交
5. 验证临界值是否正常，例如 `0/1/199/200/201`

### 2. 必填校验

1. 必填字段不输入时是否提示
2. 仅输入空格时是否按空值处理
3. 前后空格是否自动去除

### 3. 字符类型校验

1. 验证中文输入是否正常
2. 验证英文输入是否正常
3. 验证数字输入是否正常
4. 验证中英数混合输入是否正常
5. 验证特殊字符输入是否允许，如 `- _ / () # &`
6. 验证全角与半角字符是否正常
7. 验证换行、制表符等特殊输入是否符合预期

### 4. 内容合法性校验

1. 验证是否允许纯数字
2. 验证是否允许纯符号
3. 验证重复内容是否允许
4. 验证是否存在业务格式要求，如编码、电话、邮箱、统一社会信用代码

### 5. 空格处理

1. 验证首尾空格是否自动去除
2. 验证中间连续空格是否允许
3. 验证仅输入空格是否禁止保存

### 6. 安全性校验

1. 验证输入 SQL 关键字时系统是否异常
2. 验证输入 HTML 标签时页面是否被正确转义
3. 验证输入脚本内容时是否存在 XSS 风险
4. 验证接口、列表、详情页展示时是否安全

### 7. 展示校验

1. 验证超长文本是否截断或换行展示
2. 验证鼠标悬浮时是否可查看完整内容
3. 验证详情页是否完整展示文本内容
4. 验证列表页、详情页、编辑页展示是否一致

### 8. 存储与回显校验

1. 验证保存后数据库是否正确落库
2. 验证再次编辑时是否正确回显
3. 验证查询、导出、接口返回与数据库是否一致

### 9. 输入方式兼容性

1. 验证不同浏览器下输入表现是否一致
2. 验证复制粘贴输入是否正常
3. 验证输入法联想场景是否正常
4. 验证拖拽输入或批量粘贴是否正常

## 二点二、选择项类型字段测试点

### 1. 默认值校验

1. 验证是否存在默认选中项
2. 验证默认值是否符合需求
3. 验证新增、编辑、详情页默认值或回显是否一致

### 2. 必填校验

1. 验证不选择时是否允许提交
2. 验证必填未选时是否正确提示
3. 验证清空选择后是否还能提交

### 3. 选项内容正确性

1. 验证下拉选项是否完整
2. 验证选项名称是否正确
3. 验证选项顺序是否符合需求
4. 验证是否存在重复选项
5. 验证是否存在无效或脏数据选项

### 4. 选项可用性

1. 验证下拉是否可正常展开
2. 验证选项是否可正常选择
3. 验证是否支持切换选项
4. 验证已选项是否正确回显
5. 验证禁用状态下是否不可操作

### 5. 联动校验

1. 验证选择某个值后是否触发关联字段变化
2. 验证联动字段的展示、隐藏是否正确
3. 验证联动后的必填、只读、可编辑状态是否正确

### 6. 数据保存与回显校验

1. 验证保存后数据库值是否正确
2. 验证列表、详情、编辑页回显是否一致
3. 验证接口返回值与页面展示值是否一致

### 7. 边界与异常校验

1. 验证选项为空时页面是否报错
2. 验证字典值删除或失效后历史数据如何展示
3. 验证传入非法选项值时系统如何处理

### 8. 交互体验校验

1. 验证选项过多时是否支持滚动
2. 验证选项文本过长时是否完整展示或支持悬浮展示
3. 验证搜索型下拉是否支持模糊搜索
4. 验证键盘操作是否正常

### 9. 权限与配置校验

1. 验证不同角色可见选项是否正确
2. 验证配置变更后选项是否实时生效
3. 验证字典表修改后业务页面是否同步更新

## 二点三、时间类型字段测试点

### 1. 默认值校验

1. 验证是否默认带出当前日期或时间
2. 验证默认值是否符合业务规则
3. 验证新增、编辑、详情页回显是否一致

### 2. 格式校验

1. 验证日期格式是否正确，如 `YYYY-MM-DD`
2. 验证时间格式是否正确，如 `HH:mm:ss`
3. 验证日期时间格式是否正确，如 `YYYY-MM-DD HH:mm:ss`
4. 验证手工输入非法格式时是否被拦截

### 3. 必填校验

1. 验证必填时间不填时是否提示
2. 验证非必填时间留空时是否允许保存
3. 验证清空后是否能正常提交

### 4. 范围校验

1. 验证是否允许选择过去时间
2. 验证是否允许选择未来时间
3. 验证是否存在最大值或最小值限制
4. 验证边界值场景是否正常，如当天、月末、年末

### 5. 逻辑关系校验

1. 验证开始时间不能大于结束时间
2. 验证结束时间不能早于开始时间
3. 验证多个时间字段前后顺序是否符合业务规则
4. 验证跨天、跨月、跨年场景是否正常

### 6. 特殊日期校验

1. 验证闰年 `2月29日` 是否正常
2. 验证月末日期如 `30/31` 日是否正确
3. 验证不存在的日期是否被拦截，如 `2026-02-30`
4. 验证节假日、工作日相关逻辑是否符合要求

### 7. 选择器交互校验

1. 验证日期控件是否可正常打开和关闭
2. 验证是否可切换年月日
3. 验证是否支持直接输入与控件选择
4. 验证清空、重新选择是否正常

### 8. 存储与回显校验

1. 验证保存到数据库的值是否正确
2. 验证列表、详情、编辑页回显是否一致
3. 验证接口返回时间与页面展示是否一致
4. 验证是否存在时区问题

### 9. 展示校验

1. 验证列表中展示格式是否符合需求
2. 验证超长时间格式是否需要截断
3. 验证排序是否按真实时间排序，而不是按字符串排序

### 10. 异常与兼容性校验

1. 验证空值、非法值、异常值是否处理正确
2. 验证不同浏览器下时间控件表现是否一致
3. 验证移动端与桌面端选择体验是否正常

## 二点四、数字类型字段测试点

### 1. 默认值校验

1. 验证是否存在默认值
2. 验证默认值是否符合业务规则
3. 验证新增、编辑、详情页默认值或回显是否一致

### 2. 必填校验

1. 验证必填数字字段不输入时是否提示
2. 验证非必填数字字段留空时是否允许保存
3. 验证输入空格时是否按空值处理

### 3. 数值格式校验

1. 验证整数输入是否正常
2. 验证小数输入是否正常
3. 验证负数输入是否允许
4. 验证 `0` 是否允许输入
5. 验证科学计数法是否允许
6. 验证中文数字、字母、特殊字符输入时是否被拦截

### 4. 精度与位数校验

1. 验证整数位数是否符合要求
2. 验证小数位数是否符合要求
3. 验证超出最大位数时是否拦截或提示
4. 验证四舍五入、截断规则是否符合需求

### 5. 范围校验

1. 验证最小值边界是否正确
2. 验证最大值边界是否正确
3. 验证超出范围时是否提示
4. 验证边界值本身是否允许提交

### 6. 业务规则校验

1. 验证是否允许重复值
2. 验证是否必须大于 `0`
3. 验证是否允许为负数或零
4. 验证多个数字字段之间的逻辑关系是否正确

### 7. 输入交互校验

1. 验证键盘输入是否正常
2. 验证复制粘贴数字内容是否正常
3. 验证输入过程中是否自动过滤非法字符
4. 验证千分位、货币符号、百分比符号展示是否符合需求

### 8. 存储与回显校验

1. 验证保存到数据库的值是否正确
2. 验证列表、详情、编辑页回显是否一致
3. 验证接口返回值与数据库值是否一致
4. 验证是否存在精度丢失问题

### 9. 展示校验

1. 验证页面展示格式是否符合需求
2. 验证是否需要补零、保留小数位、格式化显示
3. 验证排序是否按真实数值排序，而不是按字符串排序

### 10. 异常与兼容性校验

1. 验证空值、超大值、超小值、非法值是否处理正确
2. 验证不同浏览器下输入与展示是否一致
3. 验证移动端与桌面端输入体验是否正常

## 二点五、附件上传字段测试点

### 1. 基础上传校验

1. 验证是否可正常选择文件
2. 验证是否可正常上传单个文件
3. 验证是否支持上传多个文件
4. 验证上传成功后页面提示是否正确

### 2. 文件格式校验

1. 验证允许的文件格式是否可上传
2. 验证不允许的文件格式是否被拦截
3. 验证文件后缀大小写不同时是否处理正确
4. 验证伪造后缀文件是否被识别

### 3. 文件大小校验

1. 验证小于限制大小的文件是否可上传
2. 验证等于限制大小的文件是否可上传
3. 验证超过限制大小的文件是否被拦截
4. 验证超限时提示信息是否明确

### 4. 文件名校验

1. 验证中文文件名是否支持
2. 验证英文文件名是否支持
3. 验证超长文件名是否支持
4. 验证特殊字符文件名是否支持
5. 验证重名文件上传时处理逻辑是否正确

### 5. 预览与下载校验

3. 验证参数长度超限时是否正确提示

5. 验证多余参数、空参数、空字符串参数时系统处理是否正确

1. 验证正常入参时接口是否返回正确结果
2. 验证新增、编辑、删除、查询接口是否符合业务规则

5. 验证列表接口返回条数、分页信息是否正确

### 5. 异常场景校验

1. 验证参数为空、非法、越界时接口表现是否正确

3. 验证服务异常、超时、网络中断时接口表现是否正确

### 8. 性能与稳定性校验

2. 验证大数据量查询时接口是否稳定

4. 验证长时间运行后接口是否存在异常
